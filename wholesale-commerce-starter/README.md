# Almohit Storefront

واجهة Next.js لمتجر الجملة. المصدر الوحيد للحقيقة هو Odoo.

## التشغيل المحلي

1. انسخ `.env.example` إلى `.env` في جذر هذا المجلد.
2. ثبت الحزم من هذا المجلد:

```bash
npm install
npm run dev
```

المتجر: http://localhost:8069  
Odoo: http://localhost:8070

تفاصيل الربط: `docs/local-dev.md`
